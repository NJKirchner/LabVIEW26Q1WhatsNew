Main.vi

This Continuous Measurement sample project is based on the Queued Message Handler template.

The Event Handling Loop generates messages based on user interface actions.

The Message Handling Loop processes messages generated by the Event Handling Loop, or by other messages. There are also Acquisition and Logging message handling loop subVIs, and a chart updating loop.
